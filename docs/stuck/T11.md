# T11 — exact FVG comparator unresolved

The preserved `docs/BOOTSTRAP.pdf`, page 6, visibly states the FVG ATR condition
as `= 0.1 x ATR`, while also describing a minimum gap size. The extracted
BOOTSTRAP and `docs/SOURCE_NOTES.md` explicitly leave the comparator unresolved.

Two inspections were completed: text extraction and a rendered page inspected
visually with `pdftoppm`/`view_image`. The rendering confirms the equals sign;
it does not reveal a missing greater-than glyph. Neither automatic correction
to `>=` nor interpreting the equality as the intended threshold is justified.

The implementation requires the caller to choose `fvg_comparator='eq'` or
`'ge'`. Both options are tested. The project default remains null. Exact,
unattended T11 configuration remains STUCK until the owner resolves the source
condition. ATR smoothing and swing tie treatment are also required explicit
caller policies because the source gives no defaults; supported options are
SMA/Wilder and strict/inclusive respectively. These requirements do not block
the recorder or the independent layers.
