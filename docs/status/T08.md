Known answers cover absorption into support with a maximum two-tick extension;

late footprint availability are exercised.

Definitions retained:

- Absorption median uses each price level's cumulative volume within W bars.
  Nearby volume includes UNKNOWN; dominance is an explicitly supplied fraction.
  SELL volume into support emits BUY absorption, BUY into resistance emits SELL.
- Exhaustion compares with the preceding N bars and the candidate-time symbol-day
  delta percentile, including the candidate. Equal future extreme is no extension.
- Divergence uses strict N-bars-each-side swings and confirmation timestamps.
- VPIN receives a fixed bucket size per day, scalar or a mapping keyed by
  `(instrument_key, session_date)`. `vpin_bucket_parameters` derives the preceding
  20-session average daily volume / 50 from canonical closed historical candles.
  Fractional sizes use decimal arithmetic;
  incomplete buckets remain unreported. UNKNOWN share covers the same trailing
  buckets as VPIN. Live quantities remain ESTIMATE.
- Kyle's lambda requires an explicit `simple` or `log` return convention because
  BOOTSTRAP does not specify one. Only adjacent one-minute mids generate returns;
  no LTP substitute or gap filling. Constant delta, constant return and insufficient
  observations are flagged with the relevant undefined result left null.

Every output carries availability and source references. Events include confirming
bars and late-available footprint inputs. Gaps across contributing event bars are
flagged rather than filled. No network or live calls were made.

Benchmark command: `PYTHONPATH=src python scripts/benchmark_t08.py`. Uses cached
T04 official protobuf simulation data (50 stocks, 3 context instruments, 6 hours),
processes one instrument at a time to bound memory, and includes T06 footprint
construction plus T08 VPIN, impact and events. It excludes simulation/decode.
Synthetic V=10,000, dominance=.6, and simple returns are explicit benchmark choices,
not newly invented configuration defaults. Root should insert the resulting timing

Open limitations: BOOTSTRAP leaves dominance and return convention unspecified;
callers must supply both. A missing trailing daily-volume history cannot determine
V: the parameter producer reports null with `INSUFFICIENT_DAILY_HISTORY`. No live-broker performance claim is made.

The daily parameter producer requires publication at or before 09:15 IST for
the requested session and excludes its current-day data. A daily total requires
complete nonoverlapping 375-minute regular-session coverage; no partial daily
volume is invented. Duplicate, conflicting, overlapping and incomplete candles
are flagged. Only already available prior inputs contribute. The latest 20
supplied complete session dates determine the average; observed weekday gaps
are marked `UNVERIFIED_SESSION_GAP`, since a missing weekday might be an NSE
holiday. No holiday dates are guessed or zero-filled. Known-answer tests cover
20-day fractional average, incomplete/missing history, late receipts, current-day
exclusion, duplicate totals and unverified session gaps.
