# T12: levels

Status: IMPLEMENTED; root integration and serial benchmark pending.

`layers/levels/core.py` produces canonical LEVEL_SCHEMA records for prior-session
high/low/close, immediately prior calendar-week high/low, 5/15/30-minute opening
ranges, gap intervals with fill status, and opt-in round numbers. It accepts only
canonical bar/candle contracts and only closed, available inputs. Prices remain
Decimal. Default round numbers are disabled.

Validation: `PYTHONPATH=src pytest -q tests/test_levels.py` → **13 passed**.
Known answers cover prior day/week, all three opening windows, late availability,
up/down/zero gaps, complete and partial fills, missing/straddling bars, explicit
round intervals, candle APPROXIMATE labels, duplicates, naive timestamp rejection,
empty input, exact truncation equality, and unchanged already-filled gap provenance
when a duplicate arrives later.

Opening ranges with missing interval coverage emit an INCOMPLETE diagnostic
interval with a GAP flag; they do not invent a complete OR high/low. Previously
supplied session histories with missing coverage carry INCOMPLETE_SESSION flags.
Prior-day means the last supplied completed trading session: the caller must
supply the appropriate session history/calendar, since this function does not
fetch holidays or fabricate missing sessions. Prior week means the immediately
preceding calendar week, not five rolling sessions.

The source does not define whether gap fills require a close. This implementation
marks a gap filled when a closed bar's wick reaches the prior close, and marks
partial penetration PARTIAL. Every status update is stamped with the availability
of the closed bar that demonstrates it. Gap interval width is the absolute gap
size; its SUPPORT/RESISTANCE side conveys up/down direction.

Benchmark command: `PYTHONPATH=src python scripts/benchmark_t12.py`.
It reads the shared simulated six-hour, 50-stock plus three-index cached bar day
and reports bars/second and originating tick-equivalents/second separately.
Upstream trade classification and bar construction are excluded.

No network, live calls, external credentials, or existing tests changed. No STUCK
problems. No full-suite assertion is made before root integrates the other layers.
