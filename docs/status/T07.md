## Definitions and explicit conventions

- `OFI` is snapshot `e_n`; `OFI_INTERVAL` is its developing sum within the current
  UTC receipt-minute, including the transition crossing the minute boundary.
- `OFI_NORMALIZED` reports every requested level; `MULTI_OFI_NORMALIZED` is null
  if any requested level or normalization denominator is unavailable.
- The trailing denominator is mean `(bid_qty + ask_qty) / 2` at that level,
  including the current available snapshot. Window lengths are configurable;
  BOOTSTRAP specifies no exact window lengths or bid/ask averaging convention.
- Incomplete displayed books carry `PARTIAL_DEPTH`; DI for a one-sided/missing
  book is null. A missing interval transition poisons that level's interval sum
  until the next minute rather than implicitly filling it with zero.
- Stale/duplicate snapshots emit flagged null features and never advance state.
  Missing exchange timestamps are allowed; receipt time and sequence still
  provide ordering checks. State resets for each instrument/session.
- Iceberg traded volume is the snapshot cumulative-volume delta allocated to
  observed last price, labelled `HEURISTIC`. A reset breaks its window. This
  cannot establish actual iceberg executions from a snapshot-only feed.
